# Schemas & Formats Reference

Complete reference for all JSON formats used in the work order pipeline.

## Work Order Schema

The complete structure of a work order JSON file.

### TypeScript Definition

```typescript
interface WorkOrder {
  // Unique identifier
  wo_id: string;
  
  // Scope: internal or external delivery
  request_type: "internal" | "external";
  
  // Stage: sim (test) or live (production)
  stage: "sim" | "live";
  
  // The actual work to be done
  work_order: {
    title: string;
    description: string;
    deliverable_type: string;
    priority: "critical" | "high" | "medium" | "low";
    deadline_iso: string;
  };
  
  // Who requested this work
  requestor: {
    agent_or_user: string;
    partner_name: string;
  };
  
  // How to route to Paperclip agents
  routing: {
    project_id: string;
    preferred_agents: string[];
    hitl_required_before_delivery: boolean;
  };
  
  // Where to save the deliverable
  opprrc_output: {
    audience: string;
    filename_pattern: string;
    path: string;
    also_write_to_partner_folder?: string;
  };
  
  // Evaluation & promotion settings
  eval: {
    scoring_weights: string;
    success_criteria_ids: string[];
    min_score_to_promote: number;
    requires_manual_promotion: boolean;
  };
  
  // Internal fields (added by pipeline)
  _paperclip_issue_id?: string;
  _paperclip_issue_identifier?: string;
  _eval_score?: number;
  _promoted_at?: string;
  _live_issue_id?: string;
  _live_issue_identifier?: string;
  _assigned_agent_id?: string;
  _assigned_agent_name?: string;
}
```

### Minimal Valid Example

```json
{
  "wo_id": "WO-2026-001",
  "request_type": "internal",
  "stage": "sim",
  "work_order": {
    "title": "Weekly Report",
    "description": "Generate weekly summary",
    "deliverable_type": "report",
    "priority": "high",
    "deadline_iso": "2026-04-28T17:00:00Z"
  },
  "requestor": {
    "agent_or_user": "CEO",
    "partner_name": "Finance"
  },
  "routing": {
    "project_id": "d1234567-1234-5678-9abc-def012345678",
    "preferred_agents": ["CEO", "CFO"],
    "hitl_required_before_delivery": false
  },
  "opprrc_output": {
    "audience": "BOARD-INTERNAL",
    "filename_pattern": "WO-{wo_id}-WEEKLY-{date}",
    "path": "05_REPORTS/BOARD-INTERNAL/"
  },
  "eval": {
    "scoring_weights": "default",
    "success_criteria_ids": ["completeness", "accuracy"],
    "min_score_to_promote": 0.75,
    "requires_manual_promotion": false
  }
}
```

### Field Details

| Field | Type | Required | Constraints | Example |
|-------|------|----------|-------------|---------|
| `wo_id` | string | Yes | Unique, format WO-YYYY-NNN | `WO-2026-001` |
| `request_type` | enum | Yes | "internal" \| "external" | `"internal"` |
| `stage` | enum | Yes | "sim" \| "live" | `"sim"` |
| `work_order.title` | string | Yes | 1-200 chars | `"Weekly Revenue Report"` |
| `work_order.description` | string | Yes | 1-2000 chars | `"Generate revenue..."` |
| `work_order.deliverable_type` | string | Yes | Any string | `"report"` |
| `work_order.priority` | enum | Yes | critical\|high\|medium\|low | `"high"` |
| `work_order.deadline_iso` | string | Yes | ISO 8601, future date | `"2026-04-28T17:00:00Z"` |
| `requestor.agent_or_user` | string | Yes | Name or ID | `"CEO"` |
| `requestor.partner_name` | string | Yes | Team/dept name | `"Finance"` |
| `routing.project_id` | string | Yes | Valid Paperclip UUID | `"d123..."` |
| `routing.preferred_agents` | array | Yes | 1+ agent names | `["CEO", "CFO"]` |
| `routing.hitl_required_before_delivery` | boolean | Yes | true \| false | `false` |
| `opprrc_output.audience` | string | Yes | Valid OPPRRC audience | `"BOARD-INTERNAL"` |
| `opprrc_output.filename_pattern` | string | Yes | Supports {wo_id}, {date}, {slug} | `"WO-{wo_id}-..."` |
| `opprrc_output.path` | string | Yes | Drive folder path | `"05_REPORTS/BOARD-INTERNAL/"` |
| `opprrc_output.also_write_to_partner_folder` | string | No | Drive folder path | `"SHARED/PARTNERS/"` |
| `eval.scoring_weights` | string | Yes | Valid profile name | `"default"` |
| `eval.success_criteria_ids` | array | Yes | 1+ criteria | `["completeness"]` |
| `eval.min_score_to_promote` | number | Yes | 0.0 to 1.0 | `0.75` |
| `eval.requires_manual_promotion` | boolean | Yes | true \| false | `false` |

## Evaluation Result Schema

Generated by Stage 2 (Evaluation). Stored at `EVALS/RESULTS/WO-{wo_id}-eval.json`.

### Example

```json
{
  "wo_id": "WO-2026-001",
  "eval_timestamp": "2026-04-27T14:00:00Z",
  "score": 0.88,
  "criteria_passed": ["completeness", "accuracy"],
  "criteria_failed": ["timeliness"],
  "passed_count": 2,
  "total_count": 3,
  "scoring_weights": "default",
  "sim_issue_id": "AMXA-2287",
  "sim_issue_identifier": "AMXA-2287",
  "promotion_eligible": true,
  "promotion_requires_manual_approval": false,
  "notes": "Good work order, ready for promotion"
}
```

### Fields

| Field | Type | Meaning |
|-------|------|---------|
| `wo_id` | string | Work order ID |
| `eval_timestamp` | string | When eval was done (ISO 8601) |
| `score` | number | 0.0-1.0 final score |
| `criteria_passed` | array | Criteria that passed |
| `criteria_failed` | array | Criteria that failed |
| `passed_count` | number | Number of criteria passed |
| `total_count` | number | Total criteria checked |
| `scoring_weights` | string | Profile used (e.g., "default") |
| `sim_issue_id` | string | Paperclip SIM issue ID |
| `sim_issue_identifier` | string | Paperclip issue identifier (e.g., "AMXA-2287") |
| `promotion_eligible` | boolean | Is score ≥ min_score_to_promote? |
| `promotion_requires_manual_approval` | boolean | Operator approval needed? |
| `notes` | string | Any comments |

## Run Time Card Schema

Generated by agent, used by Stage 4 (Output). Stored in Paperclip after agent execution.

### Example

```json
{
  "wo_id": "WO-2026-001",
  "agent_id": "482b3bd0-f6c3-44b6-82b4-83c2c97187d7",
  "agent_name": "CEO",
  "run_id": "run_20260427_143000_abc123",
  "issue_id": "AMXA-2288",
  "stage": "live",
  "started_at": "2026-04-27T14:30:00Z",
  "completed_at": "2026-04-27T14:45:23Z",
  "duration_minutes": 15.4,
  "model": "claude-opus",
  "tokens_input": 1200,
  "tokens_output": 43,
  "cost_usd": 0.0182,
  "deliverable_path": "05_REPORTS/BOARD-INTERNAL/WO-2026-001-REVENUE-WEEKLY-2026-04-27.md",
  "deliverable_filename": "WO-2026-001-REVENUE-WEEKLY-2026-04-27.md",
  "eval_self_score": 0.90,
  "criteria_passed": ["completeness", "accuracy"],
  "criteria_failed": ["timeliness"],
  "notes": "Report completed 5 minutes past deadline due to data gathering delays"
}
```

### Fields

| Field | Type | Meaning |
|-------|------|---------|
| `wo_id` | string | Work order ID |
| `agent_id` | string | Paperclip agent UUID |
| `agent_name` | string | Agent name |
| `run_id` | string | Unique run identifier |
| `issue_id` | string | Paperclip issue ID (e.g., AMXA-2288) |
| `stage` | enum | "sim" or "live" |
| `started_at` | string | ISO 8601 timestamp |
| `completed_at` | string | ISO 8601 timestamp |
| `duration_minutes` | number | Execution time in minutes |
| `model` | string | LLM model used (e.g., "claude-opus") |
| `tokens_input` | number | Input tokens consumed |
| `tokens_output` | number | Output tokens consumed |
| `cost_usd` | number | Total cost |
| `deliverable_path` | string | Full path to output file |
| `deliverable_filename` | string | Just the filename |
| `eval_self_score` | number | 0.0-1.0 agent's self-assessment |
| `criteria_passed` | array | Criteria agent thinks it met |
| `criteria_failed` | array | Criteria agent thinks it missed |
| `notes` | string | Agent comments |

## Chain Receipt Schema

Generated by Stage 4 (Output). Stored at `WORK-ORDER-CHAIN/WO-{wo_id}-RECEIPT.json`.

### Example

```json
{
  "wo_id": "WO-2026-001",
  "request_type": "internal",
  "agent_id": "482b3bd0-f6c3-44b6-82b4-83c2c97187d7",
  "agent_name": "CEO",
  "issue_id": "AMXA-2288",
  "issue_identifier": "AMXA-2288",
  "eval_pipeline_score": 0.88,
  "agent_self_score": 0.90,
  "completed_at": "2026-04-27T14:45:23Z",
  "execution_time_minutes": 15.4,
  "deliverable_path": "05_REPORTS/BOARD-INTERNAL/WO-2026-001-REVENUE-WEEKLY-2026-04-27.md",
  "deliverable_size_bytes": 15234,
  "deliverable_hash_sha256": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
  "tokens_consumed": 1243,
  "cost_usd": 0.0182,
  "run_time_card": {
    "wo_id": "WO-2026-001",
    "agent_name": "CEO",
    "completed_at": "2026-04-27T14:45:23Z"
  }
}
```

### Fields

| Field | Type | Purpose |
|-------|------|---------|
| `wo_id` | string | Work order ID |
| `request_type` | enum | "internal" or "external" |
| `agent_id` | string | Who did the work |
| `agent_name` | string | Agent name for readability |
| `issue_id` | string | Paperclip issue |
| `eval_pipeline_score` | number | Pipeline's eval score (0.0-1.0) |
| `agent_self_score` | number | Agent's self-assessment (0.0-1.0) |
| `completed_at` | string | Completion timestamp (ISO 8601) |
| `execution_time_minutes` | number | How long it took |
| `deliverable_path` | string | Where it's stored |
| `deliverable_size_bytes` | number | File size in bytes |
| `deliverable_hash_sha256` | string | SHA256 checksum (for integrity) |
| `tokens_consumed` | number | Total tokens (input + output) |
| `cost_usd` | number | Total cost |
| `run_time_card` | object | Full RTC for audit trail |

## Success Criteria Registry

File: `EVALS/SCORING/SUCCESS_CRITERIA.json`

### Example

```json
{
  "completeness": "Does the deliverable cover all requested sections and requirements?",
  "accuracy": "Are the facts, numbers, and conclusions correct?",
  "timeliness": "Was the work delivered by the deadline?",
  "formatting": "Is the output in the requested format (Markdown, PDF, JSON, etc.)?",
  "external_compliance": "Does the deliverable meet external requirements or standards?",
  "readability": "Is the output clear and well-organized?"
}
```

### Usage

In a work order's `eval.success_criteria_ids`:

```json
{
  "eval": {
    "success_criteria_ids": ["completeness", "accuracy", "timeliness"]
  }
}
```

Only these 3 criteria will be evaluated and scored.

## Scoring Weights

File: `EVALS/SCORING/SCORING_WEIGHTS.json`

### Example

```json
{
  "default": {
    "completeness": 0.4,
    "accuracy": 0.4,
    "timeliness": 0.2
  },
  "external_strict": {
    "completeness": 0.3,
    "accuracy": 0.5,
    "timeliness": 0.2
  },
  "internal_fast": {
    "completeness": 0.6,
    "accuracy": 0.3,
    "timeliness": 0.1
  }
}
```

### How to Use

In a work order's `eval.scoring_weights`:

```json
{
  "eval": {
    "scoring_weights": "external_strict"
  }
}
```

This makes accuracy worth more in the final score.

### Calculation Example

WO with criteria ["completeness", "accuracy", "timeliness"], profile "default":
- Passed: completeness ✓, accuracy ✓, timeliness ✗
- Weights: 0.4, 0.4, 0.2
- Score: 0.4 + 0.4 + 0.0 = 0.8
- **Result: 0.8 / 1.0 = 0.80 (normalized)**

## OPPRRC Output Map

File: `OPPRRC_OUTPUT_MAP.json`

Maps work order audiences to delivery paths.

### Example

```json
{
  "BOARD-INTERNAL": "05_REPORTS/BOARD-INTERNAL/",
  "CLIENTS-EXTERNAL": "05_REPORTS/CLIENTS-EXTERNAL/",
  "OPERATIONS": "04_OPERATIONS/INTERNAL/",
  "FINANCE": "05_REPORTS/FINANCE/",
  "MARKETING": "03_MARKETING/CAMPAIGNS/",
  "ENGINEERING": "02_ENGINEERING/DELIVERABLES/"
}
```

### Usage

In a work order's `opprrc_output.audience`:

```json
{
  "opprrc_output": {
    "audience": "CLIENTS-EXTERNAL",
    "path": "05_REPORTS/CLIENTS-EXTERNAL/"
  }
}
```

## Paperclip Issue Structure

How work orders are represented as Paperclip issues.

### Issue Description Format (from Work Order)

```
[WORK ORDER]
ID: WO-2026-001
Request Type: internal
Priority: high
Deadline: 2026-04-28T17:00:00Z
Deliverable Path: 05_REPORTS/BOARD-INTERNAL/

---

TASK DESCRIPTION

Generate the weekly revenue summary for board review.

DELIVERABLE SPECIFICATIONS

- Format: Markdown
- Include:
  - Total revenue by product line
  - YoY growth comparison
  - Key metrics dashboard
  - Recommendations

SUCCESS CRITERIA

- Completeness: all sections included
- Accuracy: numbers verified
- Timeliness: delivered by deadline
```

### Issue Metadata (Labels)

SIM issues:
```
["sim", "evaluation", "wo:WO-2026-001"]
```

LIVE issues:
```
["live", "wo:WO-2026-001", "type:report", "priority:high"]
```

## Error Response Format

When something goes wrong, errors are written to `PROCESSING/FAILED/WO-{wo_id}-error.json`.

### Example

```json
{
  "wo_id": "WO-2026-001",
  "error": "Invalid JSON syntax",
  "error_detail": "Unexpected token } at line 45 column 3",
  "stage": "intake",
  "timestamp": "2026-04-27T14:00:00Z",
  "original_file": "WORK_ORDERS/INTERNAL/INBOX/WO-2026-001.json",
  "recovery_steps": [
    "Check JSON syntax (use a JSON validator)",
    "Ensure all required fields are present",
    "Re-upload the corrected file",
    "Re-run: node scripts/wo-pipeline.mjs intake"
  ]
}
```
